# Features

## My Anime List

- Add anime from search results
- Track watched episodes
- Change watch status automatically
- Give ratings
- Add notes
- Filter the list

## Discover

Anime can be searched using the Jikan API and added to the personal list.

## Reminders

Reminders can be set for an anime episode. Daily, weekly and monthly repeats are supported.

## Data

Anime data, reminders and the selected theme are stored in the browser using localStorage.
